# 購物記本（SnapsShopList）

目前版本：V0.11.4
部署目標：iOS 26、iPhone 16／iPhone 17 Pro
Bundle ID：`com.atex1.SnapshotBuyCheck`

## 功能總覽

購物記本是一個以相機為入口的食品採買與價格管理 App。使用者可以掃描一維條碼、手動建立無條碼商品，或從照片辨識條碼；掃描後會先在首頁顯示商品與最新價格，再進入完整資料頁。

商品資料包含名稱、條碼、照片、價格、購買數量、容量、單位、店家／分店、特價、買一送一、購買時間、GPS 區域，以及可選的品牌與廠商。照片可直接拍攝或從相簿選取，最多保存五張，也會嘗試保存到系統相簿。

採買記事依時間、店家與價格整理歷次紀錄，支援商品編輯、單筆或整項刪除、暫存後續編輯，以及無照片快速儲存。價格記憶助手會計算最低價、最高價、平均價、最便宜店家與每 100 g／ml（大容量以每 1 L）單價，並將買一送一與購買數量換算為實際單價。

食材庫可標記家中現有食材、輸入購入時間與保存期限、編輯或標記已用畢；海外模式則支援 JPY、KRW、USD、EUR 等貨幣、OCR 名稱擷取及海外購物數量資料。快速模式提供拍照、價格與暫存的快速入口，完整資料可稍後補齊。

## 資料與同步

資料以 SwiftData 保存，支援備份、匯入、資料統計、清除資料與最近三次歷史備援。雲端同步由使用者在 App 設定中選擇位置後執行，格式包含 schema 版本與照片資料；同步前會先建立本機備份。

## 建置與測試

使用 Xcode 開啟 `SnapsShopList.xcodeproj`，以 iOS 26 SDK 建置。相機、相簿、定位、音量鍵快門與真實雲端往返必須在實機驗證；模擬器僅能驗證編譯、一般介面與測試資料流程。

支援程式集中在 [Sources/Support](Sources/Support)，測試集中在 [tests](tests)，歷史說明、路線圖與驗證報告集中在 [docs](docs)。主目錄只保留目前版本的 App 原始碼與必要資源。
