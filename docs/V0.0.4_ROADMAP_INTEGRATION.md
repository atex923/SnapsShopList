# V0.0.4 建議路線承接表

V0.0.5 已把先前規劃的方向整合進「價格記憶助手」主線。

## 本版已完成

- 價格記憶：掃描後顯示最低、平均、最高有效單價，並列出最低／最高價的時間與店家。
- 標準單價：支援每 100 g／ml，包含 kg、L、cc 換算。
- 優惠換算：購買數量與買一送一都納入真正單價。
- 快速採買：首頁待買清單可從條碼與既有商品資料庫加入。
- 新商品流程：條碼不存在時直接開啟商品與第一筆採買紀錄建檔。
- 地點資料：記憶店家、分店、縣市、行政區；GPS 自動帶入行政區域，手動修改為輔。
- 維護能力：商品、單筆紀錄、照片與待買項目均有對應刪除入口。
- 除錯交接：錯誤保留成可分享的純文字 Log，供後續修改版本參考。

## 延伸到 V0.0.6

- 本次輸入價格與歷史統計的即時比較徽章。
- 連續掃描、本次購物籃與總金額。
- 店家資料合併、修正與附近店家建議。
- CSV／JSON 匯出、可驗證備份還原及誤刪復原。
- 價格走勢圖、異常值排除及多包裝規格比較。
