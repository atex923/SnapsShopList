# GitHub 版本更新規則

本儲存庫採用「根目錄最新版、`history/` 保存舊版」的整理方式。

## 每次推送新版本

1. 先確認目前根目錄版本、Build、驗證結果及工作樹狀態。
2. 將目前根目錄的完整可建置版本封存到 `history/V<舊版號>/`；已存在的歷史資料夾不得覆寫或刪除。
3. 將新版本的原始碼、Xcode 專案、資產、測試與對應文件更新到根目錄。
4. 根目錄只代表目前最新版，不建立另一層最新版資料夾。
5. 保留 `LICENSE`、`.gitignore`、本規則文件及所有既有歷史版本。
6. 編譯產物、DerivedData、裝置／使用者資料、SwiftData 資料庫、照片、Log、憑證及私密設定不得提交。
7. 推送前至少核對版本／Build、Bundle ID、`git diff --check`、提交內容及遠端分支。

## 首次匯入

首次匯入時遠端只有 `LICENSE`，因此 V0.11.2 直接成為根目錄最新版；專案原有的歷史版本保留在 `history/`。
