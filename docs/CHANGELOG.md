# 版本紀錄

## V0.11.4 (20260924)

- 設定新增「讀取 QR Code（二維條碼）」開關，預設關閉；關閉時相機與相簿條碼辨識只讀取一維零售條碼。
- 掃描到既有商品的查詢卡將「新購買」改為置中的大型膠囊按鈕。
- 新購買卡的條碼與商品名稱各自維持單行；照片更換鈕移至圖片下方，食材庫標題縮小為單行。

## V0.11.3 (20260924)

- 條碼辨識維持一維條碼優先，二維 QR Code 作為第二順位。
- 掃描到既有商品時，首頁查詢卡移除同名與相似商品列，改為直接進入「新購買」。
- 新購買頁以小商品照片、條碼、名稱、食材庫狀態、購價、購數與最近歷次購買價格優先排列，完整欄位保留在後段。

## V0.11.2 (20260923)

- 新增、補拍與更換商品照片時，每次進入商品相機都將鏡頭倍率重設為 `1.0×`。
- 切換一般鏡頭與近拍小花模式時，目標鏡頭同樣以 `1.0×` 開始。
- 條碼掃描相機流程不變；SwiftData 與備份 schema 不變。
- App 版本更新為 `0.11.2`、Build `112`。

## V0.11.1 (20260923)

- 掃描到既有商品後，新增採買改用精簡輸入順序：商品條碼與名稱、商品照片、本次付款、數量、店家、分店、特價與買一送一。
- 僅自動帶入最近紀錄的一組包裝、容量與單位，仍可修改；本次付款、店家與優惠不再沿用舊值。
- 紀錄時間與 GPS 固定在表單最下方；照片區移除操作說明。
- 條碼相機、相簿辨識與品牌／廠商 M 鈕集中到「商品」標題列，並縮短標籤、縮小字級及放寬輸入空間。
- 快速模式首頁把人物上移、快速紀錄卡移至較下方約三分之二位置。
- App 版本更新為 `0.11.1`、Build `111`；SwiftData 與備份 schema 維持不變。

## V0.11.0 (20260923)

- 快速模式首頁改為專用單卡版面，只保留「快速紀錄」卡；一般掃描、採買記事、待買、食材庫、掃描結果與草稿卡在快速模式中隱藏。
- 快速記錄卡移除小貓 App 圖示及說明小字，整張玻璃卡都可直接開啟快速相機紀錄。
- 快速模式首頁下方改用拿放大鏡奔跑的透明綠色角色；一般模式仍保留站立及掃描後倒地角色。
- 海外商品預設不列入台灣食材庫；海外商品詳細頁可手動加入台灣食材庫，且不會因此建立台幣採買紀錄或出現在台灣採買記事。
- 首頁待買功能拆成「建立商品」及「待買清單」兩張並列卡；待買建立頁的條碼欄提供即時相機掃描及相簿照片辨識。
- 待買清單新增商品列相機按鈕，可直接以該商品開啟快速採買紀錄；國內與海外模式各自顯示相符幣別。
- 設定關閉「顯示快速模式開關」時，會同步強制關閉目前快速模式，首頁快速記錄卡立即隱藏。
- App 版本更新為 `0.11.0`、Build `110`、製作日期更新為 `20260923`；SwiftData 與備份 schema 維持不變。

- 完成一組包裝開關、商品輸入欄、詳細資料、GPS 與價格記憶助手的靠左對齊及欄位寬度修正。
- App 版本更新為 `0.10.2`、Build `102`、製作日期更新為 `20260922`；SwiftData 與備份 schema 維持不變。

## V0.10.1 (20260916)

- App 版本更新為 `0.10.1`、Build `101`；SwiftData 與備份 schema 維持不變。

## V0.10.0 (20260916)

- 待買清單新增專用簡化建立頁，只保留照片、條碼、名稱、價格、店家及分店；商品名稱為唯一必填，價格可選填。
- 新增 `wishlistQuote` 待買比價語意；可納入最高／最低價與價格記憶助手，但不計入最近正式購買、食材庫或海外購物數量。
- 待買項目新增幣別，國內模式只顯示 TWD，海外模式只顯示非 TWD；採買記事同步依模式過濾正式購買紀錄。
- 備份與同步交換格式升級為 schema 5，加入待買幣別與待買比價狀態，維持 schema 1～4 匯入相容。
- 條碼與商品名稱輸入區加寬；店家與單位歷史入口統一為立體玻璃圖示。
- 「一組包裝」開關改成由左往右推進，保留至少 44 pt 操作區與 VoiceOver 狀態。
- 食材庫日期統一為 `yyyy年MM月dd日（民國YYY年）`，保存期限使用紅色並與購入時間對齊。
- 首頁加入透明背景綠色角色；未顯示結果時站立，掃描結果展開時切換成倒地狀態且位於結果卡後方。
- App 版本更新為 `0.10.0`、Build `100`，製作日期更新為 `20260916`。

## V0.9.1 (20260915)

- 資料同步新增「設定雲端位置」，記住使用者選擇的 iCloud Drive 或 Google Drive 資料夾。
- 「立即同步」先驗證雲端服務與資料夾，再自動尋找 `.snapssync`；缺少設定時顯示明確提示。
- 雲端資料夾沒有同步檔時跳出確認，確認後建立 `SnapsShopList.snapssync` 並立即完成第一次同步。
- 移除獨立的「建立第一份同步檔」按鈕，避免新建與同步流程重複。
- 完整備份按鈕改為「建立完整備份到雲端硬碟」，可在系統檔案畫面選擇 iCloud Drive 或 Google Drive。
- App 版本更新為 `0.9.1`，Build 更新為 `91`；SwiftData 與備份 schema 維持不變。

## V0.9.0 (20260915)

- 設定頁新增「顯示快速模式開關」，預設關閉；首頁快速模式狀態只保留於本次 App 執行期間，冷啟動自動關閉。
- 首頁設定齒輪移至左上角，快速模式開關位於右上角；快速模式開啟後固定顯示 App 小圖案及藍色圓形相機鈕。
- 新增快速紀錄畫面：價格為必要欄位，商品名稱、店家、數量、容量、單位與 GPS 均可稍後補齊；每個輸入欄位可個別清除。
- 快速草稿只存於本機 Application Support，最多暫存10張照片；正式儲存時依時間排序並最多選取5張，30天未修改的孤立草稿會清理。
- 新增 `recordStatus`、`quantityWasEntered` 與 `locationSource`。數量空白的紀錄可參與原始價格比較，但不進海外購物數量庫，也不假設為購買1組。
- 商品詳細頁新增「歷次比較價格」；數量未知時顯示「數量未填」，容量足夠時才提供明確標示的容量換算參考。
- 海外 OCR 支援相機及系統相簿；相簿照片可讀取 GPS metadata，辨識候選仍須使用者確認後才填入。
- 備份格式升級為 schema 4，維持 schema 1～3 匯入相容；快速草稿不加入備份、CloudKit 或 `.snapssync`。
- App 版本更新為 `0.9.0`，Build 更新為 `90`。
