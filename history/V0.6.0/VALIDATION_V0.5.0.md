# SnapsShopList V0.5.0 驗證報告

驗證日期：2026-09-09

## 功能與資料驗證

- 食材庫資料模型：通過；可區分目前在庫及已用畢歷史，商品刪除時會級聯清除對應資料。
- 食材庫操作：通過編譯與邏輯檢查；新增紀錄會明確回寫商品關聯，既有資料預設唯讀，按「編輯」後才能修改，「已用畢」只在編輯狀態顯示並需再次確認。
- 商品詳細資料：通過；最下方食材庫卡片顯示最新購入時間，展開後顯示購入、保存期限及已用畢歷史。
- 首頁狀態：通過；新增淺棕色食材庫卡片，掃描後以綠色「在庫」文字或警告三角形表示在庫狀態。
- 首頁簡單查閱：通過；歷次價格下方顯示食材庫狀態，在庫時列出最近購入時間與保存期限。
- 待買清單空白提示：通過；顯示「尚無資料，點擊開始增加」。
- 條碼相機：通過編譯；一維條碼維持優先，小花近拍預設開啟，硬體不支援時按鈕停用。
- 鍵盤收合：通過回歸檢查；商品建立、新增採買及採買編輯仍在鍵盤工具列最右側提供「隱藏鍵盤」。

## 備份與相容性

- 完整備份升級為 schema 3，包含商品、採買紀錄、照片、店家、待買清單及食材庫歷史。
- schema 1 與 schema 2 舊備份解碼及驗證：通過；缺少食材庫資料時以空資料匯入。
- schema 3 合併去重、清除全部資料及覆蓋還原：通過。
