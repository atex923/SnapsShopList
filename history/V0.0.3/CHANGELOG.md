# 版本紀錄

## V0.0.3 (20260906)

- 移除掃描完成後固定 0.35 秒延遲，改由相機畫面關閉事件銜接資料表單。
- AVCaptureSession 設定、啟動及停止移至專用背景佇列。
- 新增條碼手動輸入，提供相機辨識失敗時的替代方式。
- 相機或資料庫查詢失敗時顯示明確訊息，不再停留於無回應畫面。
- 商品照片加入 SwiftData 外部儲存影像資料，改善跨裝置同步完整性。
- 舊版本機照片啟動時自動補入影像資料，保留既有資料。
- 照片儲存前縮放至最長邊 1600 點並壓縮，降低裝置與 iCloud 空間用量。
- 修正新增、刪除照片失敗時的資料庫回復與檔案清理順序。
- 新增商品、條碼及店家搜尋。
- 既有商品再次採買時自動帶入上次常用欄位。
- 強化本地化數字解析、數值範圍及重複條碼檢查。
- Debug 直接使用既有本機資料庫，避免無 iCloud entitlement 時先嘗試 CloudKit。
- 完整保存上一版於 `history/V0.0.2/`。

## V0.0.2 (20260906)

- 掃描條碼後自動查詢 SwiftData 商品資料庫。
- 找不到商品時顯示完整的商品與本次採買建檔表單。
- 找到既有商品時直接新增採買紀錄。
- 建檔時可拍攝商品照片，每項商品合計最多三張。
- 資料儲存失敗時回復 SwiftData 變更並移除未完成的照片檔案。
- 完整保存上一版於 `history/V0.0.1/`。

- 建立「採買記事工」iPhone App 專案。
- 完成 iPhone 16 直向首頁雙方塊配置。
- 完成相機食品條碼讀取與條碼文字顯示。

- 完成商品歷史清單與商品詳細歷史頁。
- 完成最多三張商品照片的拍攝、相簿保存、瀏覽與刪除流程。
