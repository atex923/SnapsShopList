# 版本紀錄

## V0.4.0 (20260909)

- 條碼掃描改為優先接受 EAN、UPC、Code 128／93／39 等一維條碼，QR Code 僅作為沒有一維結果時的備援。
- 掃描既有商品後，在首頁結果及完整商品頁顯示名稱相同或相似商品，附上最近價格與換算單價並可直接進入。
- 首頁移除作者與錯誤三角按鈕，只在底部保留版本及製作日期；作者 Atex Lin 與錯誤紀錄入口移入「設定 → 關於」。
- 新增與編輯表單將照片置頂，付款與數量優先；所有欄位名稱固定顯示，品牌、廠商及 GPS 座標收進下拉區塊。
- 照片按鈕置中，說明統一為「每項商品最多保存3張照片」。
- 店家記憶會連同分店帶入；新增單位記憶，可快速重用最近輸入的 g、ml、包、盒或自訂單位。
- 商品歷史卡改為顯示「購買總價」與「單品最低」；歷次採買紀錄排序名稱統一為「時間／價格／店家」。
- 液體容量超過 1000 ml 時，單價以每 1 L 顯示；其他重量與容量維持每 100 g／ml。
- 商品照片新增正方形、4:3 與 3:4 中央裁切，裁切結果會壓縮後更新既有照片資料。
- 完整保存 V0.3.0 於 `history/V0.3.0/`。
- 本版依需求不啟用海外模式、OCR、AI 與網頁搜尋；新紀錄固定使用 TWD，既有外幣資料仍保持相容。

## V0.3.0 (20260908)

- 商品新增「品牌」及「廠商」兩個獨立非必填欄位；建立、新增採買與編輯頁皆可維護。
- 商品詳情顯示品牌與廠商，採買記事搜尋同時支援名稱、品牌、廠商、條碼與店家。
- 採買紀錄新增 TWD、JPY、KRW、USD、EUR 五種貨幣及對應符號。
- 設定頁新增預設貨幣，新採買會沿用目前設定；每筆資料仍可個別切換。
- 首頁價格漲跌、最低／最高價與價格記憶助手只比較相同貨幣，不直接混算外幣。
- 備份格式升級為 schema 2，保存品牌、廠商與貨幣；仍可讀取 schema 1 舊備份，缺少貨幣時以 TWD 匯入。
- SwiftData 新欄位皆提供安全預設值，既有商品及採買紀錄可輕量遷移。
- App 圖示換成手繪貓咪、放大鏡與條碼圖案，依使用者要求移除紅色箭頭。
- 完整保存 V0.2.0 於 `history/V0.2.0/`。
- 下一階段規劃「海外模式」總開關；國內模式不載入 OCR、AI 或網頁搜尋功能。

## V0.2.0 (20260907)

- 掃描畫面新增「建立無條碼商品」，相機無法使用時也能直接進入。
- 無條碼商品使用不顯示的 `MANUAL-UUID` 內部識別碼，既有資料模型及備份格式保持相容。
- 商品建立、採買新增、採買編輯及待買清單一律顯示「無條碼」，不顯示內部識別碼。
- 手動輸入商品名稱達 2 個字時，提示最多 5 筆名稱相近商品，可改用既有商品避免重複資料。
- 無條碼商品可直接加入待買清單，並沿用商品照片、採買歷史與價格記憶助手。
- 容量欄位改稱「容量／實際重量」，明確支援秤重商品及每 100 g／ml 單價換算。
- 新增 `ManualProductSmoke`，驗證無條碼識別、備份還原及 750 g／150 元換算為每 100 g／20 元。
- 完整保存 V0.1.4 於 `history/V0.1.4/`。
