# SnapshotBuyCheck V0.0.5 建議路線圖

V0.0.4 已優先完成店家記憶、分店與地區、GPS 及錯誤紀錄；原訂的價格記憶助手順延至 V0.0.5。

## 建議主題：價格記憶助手

### 第一優先：掃描後立即協助判斷

- 顯示上次價格、歷史最低價、平均價及紀錄筆數。
- 顯示最低價出現的店家與日期。
- 依本次價格顯示「歷史低價」「低於平均」「高於平均」徽章。
- 支援每 100 g、每 100 ml、每個／每包的標準單價。
- 買一送一自動換算有效單價。

### 第二優先：購物現場更快

- 新增「連續掃描模式」，一次採買多項商品，不必每次回首頁。
- 建立本次購物籃與即時合計金額。
- 增加店家管理頁，可修改、合併或刪除記錯的店名與分店。
- 以 GPS 建議附近曾使用的店家，但不強制取得位置權限。
- 可從歷史商品一鍵加入今日採買。

### 第三優先：資料安全與分享

- CSV／JSON 匯出、完整照片備份與可驗證還原。
- 錯誤紀錄可匿名匯出，供除錯使用，並自動移除 GPS 與商品內容。
- 正式 CloudKit 多裝置同步狀態與最後同步時間。
- 家庭共享商品價格資料庫。
- 誤刪商品或採買紀錄的復原功能。

### 後續版本候選

- 保存期限、庫存數量與低庫存購物清單。
- GS1 Data Matrix 自動讀取有效日期。
- 收據照片辨識與批次建立採買紀錄。
- Widget 顯示最近低價與待買商品。
- Siri／App Intents：「記錄牛奶 89 元」與「這個商品最低多少」。

## 不建議立刻加入

- AI 食譜、飲食營養分析、會員卡及賣場廣告。
- 原因：這些功能會明顯擴大隱私、資料來源與維護範圍，且會模糊「快速記住買過的價格」這個核心。
