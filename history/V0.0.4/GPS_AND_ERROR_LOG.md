# GPS 與錯誤紀錄說明

## GPS

- 只在「建立商品資訊」或「新增採買紀錄」畫面請求定位。
- 使用 iOS 的「使用 App 期間」權限，紀錄經緯度與水平誤差。
- 使用者拒絕、裝置限制或暫時定位失敗時，採買資料仍可儲存，GPS 欄位保持空白。
- V0.0.4 不會在背景持續追蹤，也不會用 GPS 自動推定地址。

## 程式錯誤紀錄

- 首頁右上角驚嘆號按鈕可開啟「程式錯誤紀錄」。
- 紀錄資料庫、條碼相機、商品照片、手機相簿、GPS 及資料移轉錯誤。
- 最多保留最近 200 筆，可由使用者手動全部清除。
- 檔案保存在 App 的 Application Support 目錄，不會寫入手機相簿。
- 錯誤紀錄可能包含錯誤發生情境，但不刻意記錄 GPS 座標或照片內容。
