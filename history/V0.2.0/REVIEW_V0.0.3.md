# SnapshotBuyCheck V0.0.3 程式檢討

檢討日期：2026-09-06

## 已修正

1. 掃描切頁延遲
   - 原本以固定 0.35 秒等待掃描 sheet 關閉，較慢的裝置可能仍衝突，較快的裝置則平白等待。
   - 改用 `fullScreenCover` 的 `onDismiss`，畫面真正關閉後立即查詢並切頁。

2. 相機阻塞畫面
   - 原本在 View Controller 主執行緒設定 AVCaptureSession。
   - 改由專用 serial queue 負責設定、啟動及停止，相機畫面開啟時更順暢。
   - 相機無法設定時提供錯誤訊息及手動輸入入口。

3. iCloud 只有照片檔名
   - 原模型只同步本機檔名，另一台裝置可能沒有對應 JPEG。
   - 新增 `@Attribute(.externalStorage) imageData`；新照片同步實際 JPEG 資料，舊照片也會自動補資料。

4. 儲存與刪除一致性
   - 照片資料庫儲存失敗時，現在會 rollback 並刪除剛建立的檔案。
   - 刪除照片時先確認資料庫成功，再移除本機檔案，避免資料仍在但檔案已消失。

5. 輸入效率與正確性
   - 既有商品自動帶入上一筆店家、容量、單位與價格。
   - 支援地區格式的小數點或逗號，阻止負價格與零容量。
   - 儲存新商品前再次檢查重複條碼。
   - 歷史頁新增名稱、條碼、店家搜尋。

6. 儲存空間
   - 照片最長邊限制 1600 點，JPEG 品質 0.82，兼顧商品辨識與同步容量。
