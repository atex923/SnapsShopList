# SnapshotBuyCheck V0.0.7 建議路線圖

V0.0.6 已完成固定玻璃首頁、自訂商品相機、近拍模式與啟動效能改善。V0.0.7 建議聚焦在更快的現場判斷與資料復原。

## 建議主題：價格判斷與購物籃

### 第一優先：掃描後的即時判斷

- 輸入本次價格時即時顯示「刷新歷史低價」「低於平均」「高於平均」徽章。
- 增加價格走勢圖及指定店家的價格篩選。
- 補充每個／每包標準單價，並允許同一商品保存不同包裝規格。
- 顯示統計紀錄筆數，並讓使用者排除異常價格。

### 第二優先：購物現場更快

- 新增「連續掃描模式」，一次採買多項商品，不必每次回首頁。
- 建立本次購物籃與即時合計金額。
- 增加店家管理頁，可修改、合併或刪除記錯的店名與分店。
- 以 GPS 建議附近曾使用的店家，但不強制取得位置權限。
- 可從歷史商品一鍵加入待買清單，並將已買項目勾選完成。

### 第三優先：資料安全與分享

- CSV／JSON 匯出、完整照片備份與可驗證還原。
- 錯誤紀錄可匿名匯出，供除錯使用，並自動移除 GPS 與商品內容。
- 正式 CloudKit 多裝置同步狀態與最後同步時間。
- 家庭共享商品價格資料庫。
- 最近刪除區與限時復原，降低誤刪風險。

### 後續版本候選

- 保存期限、庫存數量與低庫存購物清單。
- GS1 Data Matrix 自動讀取有效日期。
- 收據照片辨識與批次建立採買紀錄。
- Widget 顯示最近低價與待買商品。
- Siri／App Intents：「記錄牛奶 89 元」與「這個商品最低多少」。

## 不建議立刻加入

- AI 食譜、飲食營養分析、會員卡及賣場廣告。
- 原因：這些功能會明顯擴大隱私、資料來源與維護範圍，且會模糊「快速記住買過的價格」這個核心。
