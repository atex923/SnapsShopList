# SnapsShopList V0.5.0

中文名稱：購物記本

V0.5.0 新增「食材庫」：首頁可快速查看掃描商品是否仍在庫，綠色圓點代表在庫，警告三角形代表尚未登記。食材庫依最近採買時間排序，可記錄購入時間與保存期限；商品用畢後保留歷史，方便追蹤重複購買與使用週期。

商品詳細資料最下方會顯示最近一次食材庫購入日期，展開後可查看每次購入、保存期限與已用畢日期。完整備份格式升級為 schema 3 並包含食材庫歷史，同時維持 schema 1、2 舊備份匯入相容性。

條碼掃描頁新增小花近拍切換。支援近距離對焦的 iPhone 會在掃描開始時主動啟用，仍維持一維商品條碼優先辨識。

V0.4.1 正式加入「海外模式」。設定頁開啟後可選擇 TWD、JPY、KRW、USD 或 EUR，選定貨幣會持續套用到後續新紀錄；關閉時新紀錄固定使用 TWD，既有外幣資料不會被改寫。

海外模式可用相機擷取商品名稱、店家、品牌及廠商文字。本機 Apple Vision OCR 只在使用者按下擷取按鈕後建立，支援繁體中文、英文、日文及韓文；國內模式不顯示也不啟動這些入口。

掃描後可開啟「查詢正確外文名稱」，先查看將送出的條碼與文字，再選擇網頁搜尋或分享給 AI／搜尋 App。此流程不會分享照片、GPS、價格或採買歷史，結果必須由使用者確認後再填入。

首頁掃描按鈕採淺藍色玻璃底色與黑色圖文。掃描後先留在首頁顯示最新價格及相較上次的漲跌，點擊結果卡才開啟完整商品頁。新增採買資料可用照片加價格快速「暫存」，完整欄位符合條件後顯示「儲存」。

設定頁提供完整備份、匯入、資料統計與清除全部資料。備份使用系統檔案畫面，因此可選擇 iCloud Drive、Google Drive、我的 iPhone 或其他檔案服務。

V0.4.0 以台灣日常快速記錄為主：一維條碼優先辨識，輸入表單把照片移到最上方，付款與數量優先，所有欄位使用固定名稱，品牌、廠商與 GPS 詳細座標收進下拉區塊。單位會記住最近輸入值。

掃描既有商品後會顯示名稱相同或相似的商品、價格與換算單價；商品詳細頁也能直接進入相關商品。歷次採買紀錄可依「時間／價格／店家」排列。超過 1000 ml 的液體改以每 1 L 顯示單價，照片支援正方形、4:3 與 3:4 中央裁切。

商品卡顯示最近一次的「購買總價」及跨紀錄的「單品最低」。作者與錯誤紀錄入口移入「設定 → 關於」，首頁底部只保留版本與製作日期，讓主要資訊區有更多空間。

V0.3.0 已建立 TWD、JPY、KRW、USD、EUR 資料相容能力；V0.4.1 只有在海外模式開啟時顯示貨幣切換，並把貨幣放在採買欄位最後。舊外幣資料與備份仍可正確讀取及顯示。

V0.3.0 同時換用使用者指定的手繪貓咪條碼圖示，右下紅色箭頭已移除。

V0.2.0 開始支援無條碼商品。在掃描畫面按「建立無條碼商品」，即可記錄市場蔬果、散裝食品、熟食或其他沒有包裝條碼的品項。App 使用不顯示的內部 UUID 識別商品，使用者畫面只會看到「無條碼」。輸入名稱達 2 個字時會提示最多 5 筆可能相同的既有商品，可直接沿用以避免重複建立。

秤重商品可在「容量／實際重量」填入重量並選擇 g、kg、克或公斤；價格記憶助手會換算每 100 g。液體可使用 ml、cc、L、公升並換算每 100 ml，買一送一及多件購買仍會納入真實單價。

掃描到既有商品後，「新增採買紀錄」會保留最新一筆的購買數量、單位、容量、特價、買一送一與地區資料，但清空店家、分店及價格，方便快速填入本次價格與購買店家。商品既有照片會直接顯示，並可更換、刪除或補拍；選擇記憶店家時會連同分店及地區帶入。

V0.1.3 已重新驗證備份、合併去重、清除及還原流程；清除全部資料會明確刪除商品、採買紀錄、照片、店家及待買清單，也會處理舊資料可能留下的孤立紀錄。

待買清單以單行顯示商品名稱、條碼與刪除鍵；整行放不下時條碼改顯示「...」，點擊可浮出完整內容。商品照片的操作列位於照片下方且不使用黑色底板。

首頁使用響應式寬度規格：iPhone 16 維持緊密配置，iPhone 17 Pro 的 402 pt 寬度會放大操作卡、圖示與間距，同時保持單頁不捲動。

## V0.1.0 快速紀錄與編輯

- 無有效資料時「儲存」按鈕反白停用。
- 至少一張照片加有效價格時，按鈕改為「暫存」並允許快速保存。
- 商品名稱、店家、價格、單位及購買數量符合條件時，按鈕顯示「儲存」。
- 採買記事中的紀錄可再次編輯；暫存資料有清楚標記，補齊後會轉為正式紀錄。
- 新增採買不沿用上一筆價格，必須輸入本次價格。
- 多張商品照片以最早拍攝時間優先，左右切換依時間向後瀏覽。

## V0.0.7 效能與可靠性更新

- 條碼掃描的 `AVCaptureSession` 初始化、設定、啟動與停止全部移至專用背景佇列。
- 定位模組完整追蹤權限與精確度；約略定位會明確顯示，暫時性失敗自動重試一次。
- 表單驗證、數字解析、價格換算與店家識別拆成可獨立測試的 `PurchaseLogic.swift`。
- 新拍照片只保存一份 SwiftData 外部資料；縮圖與 JPEG 壓縮改為背景處理，舊照片會安全整併後移除重複檔案。
- 商品歷史清單每次更新只計算一次最新紀錄，店家記憶與待買清單刪除改由資料庫 Predicate 查詢。
- `NumberFormatter` 改為快取共用，價格統計共用同一次最新紀錄計算。
- Log 平時只更新 JSON；使用者按下分享時才產生文字 `.log`，減少錯誤發生時的重複 I/O。
- 首頁雙方格移除 `GeometryReader`，改由 SwiftUI 自適應正方形版面。
- 修正拍照後巢狀相機頁可能連同商品表單一起關閉；現在只關閉相機並留在原表單。
- 拍照完成後立即嘗試加入系統相簿，不再等到儲存商品資料；權限拒絕或寫入失敗會顯示原因。
- 商品照片為完全選填；沒有照片可直接儲存，照片壓縮失敗也只略過照片，不會回復或取消商品資料。
- 建立／新增商品中的相機改為由表單根畫面管理的獨立全螢幕層，避免子區塊重繪時關閉整個建檔流程。
- 商品建檔表單重新排列：商品欄下方為相機；店家／分店後依序為價格、購買數量、單位、容量；縣市與行政區移至 GPS 區塊。
- 分店與容量改為選填；容量留白以未填寫保存，不影響商品資料儲存。

## V0.0.6 新增與修正

- 首頁及手機桌面名稱統一為「購物記本」。
- 首頁取消捲動，三個主要功能區塊縮短間距並固定在單一 iPhone 16 畫面。
- 上方兩個方格採相同圖示、標題與副標題高度，改用 iOS 26 Liquid Glass 效果。
- 背景改為蘋果淺綠色，主色更新為 Apple system green。
- 版號與作者資訊移到畫面底部；錯誤 Log 入口縮小並移至作者資訊右側。
- 商品照相由舊式 UIImagePickerController 改為 AVFoundation 自訂相機，降低開啟相機閃退風險。
- 相機設定、啟動、停止、切換鏡頭及拍照均在專用背景佇列執行，錯誤會寫入 Log。
- 支援具有超廣角鏡頭的裝置顯示「近拍小花」按鈕，啟用近距離自動對焦。
- 所有採買輸入表單的鍵盤上方增加「隱藏鍵盤」按鈕。
- 舊照片資料移轉延後到首頁顯示後才執行，完成後不再於每次啟動重複掃描。

## V0.0.5 新增功能

- 以「價格記憶助手」為核心：掃描既有商品後立即顯示歷史最低、平均及最高有效單價。
- 最低價與最高價同時顯示發生時間和店家；最便宜店家可直接辨識。
- 支援每 100 g／ml 單價，kg、L、cc 會自動換算。
- 「本次付款總價」依購買數量換算每件有效單價；買一送一再以實際取得雙倍件數計算。
- 首頁新增待買清單，可掃描既有商品加入、調整數量或移除；未知條碼會進入商品建立流程。
- GPS 定位成功後以 iOS 26 MapKit 自動帶入縣市與行政區，輸入欄位仍可手動修改。
- 新增刪除功能：可刪除待買項目、單筆採買紀錄，或連同歷史紀錄與 App 內照片刪除整項商品。
- 執行錯誤除畫面內最近 200 筆外，另存為 `SnapsShopList-runtime.log`，可從錯誤紀錄頁分享供後續除錯。
- 購買數量預設為 1 且僅接受正整數；舊版採買紀錄升級後仍以數量 1 顯示。
- 完整承接 V0.0.4 建議路線，詳見 `V0.0.4_ROADMAP_INTEGRATION.md`。

## V0.0.4 新增功能

- 記住曾輸入的店家、分店、縣市及行政區，新增紀錄時可從最近使用清單快速帶入。
- 同一組店家資訊會更新使用次數與最近使用時間，不會每次重複新增。
- 採買紀錄新增分店、縣市、行政區欄位，歷史清單、搜尋及詳細頁均可顯示。
- 建立紀錄時可取得 GPS 經緯度及定位誤差；拒絕定位或定位失敗時仍可正常存檔。
- 首頁新增「程式錯誤紀錄」，保留最近 200 筆資料庫、照片、相機、GPS 與相簿錯誤，可查看及清除。
- 新增定位用途說明，僅在建立採買紀錄頁請求「使用 App 期間」定位權限。

## 既有功能

- 使用相機讀取 EAN-8、EAN-13、UPC-E、Code 39、Code 93、Code 128 與 QR Code。
- 掃描後顯示條碼內容，並自動搜尋 SwiftData 商品資料庫。
- 找不到條碼時開啟「建立商品資訊」，可輸入名稱、時間、店家、容（重）量、單位、價格、購買數量、特價及買一送一。
- 找到既有商品時開啟「新增採買紀錄」，保留同一商品的歷次價格與店家資料。
- 商品歷史清單及商品詳細歷史頁。
- 商品照片拍攝、手機相簿保存、最多三張、切換瀏覽與刪除。
- 商品照片以 SwiftData 外部儲存資料同步；舊版本機 JPEG 僅供一次性相容移轉。
- 相機工作移至專用背景佇列，掃描完成後依畫面關閉事件立即切頁，不再使用固定等待時間。
- 條碼無法辨識時可手動輸入。
- 歷史頁可搜尋商品名稱、條碼或店家。
- 再次購買既有商品時，自動帶入上次店家、容量、單位與價格。
- 價格支援小數點與逗號格式，並檢查負數及零容量。
- SwiftData 本機資料庫及 CloudKit 私有資料庫同步架構。

## iCloud 設定

專案預設 CloudKit Container 為 `iCloud.com.atex1.SnapshotBuyCheck`。第一次使用時，請在 Xcode 的 Signing & Capabilities 確認：

1. Team 已選擇正確的 Apple Developer 團隊。
2. iCloud 已啟用 CloudKit，並勾選上述 Container。
3. Background Modes 已啟用 Remote notifications。

CloudKit 功能需要 Apple Developer 帳號具備建立 iCloud Container 的權限。

目前專案的 Debug 設定使用本機 SwiftData，讓 Personal Team 可以安裝到實機；Release 設定保留 CloudKit entitlement。升級或改用支援 iCloud 的 Apple Developer 團隊後，以 Release 建置即可啟用同步。
