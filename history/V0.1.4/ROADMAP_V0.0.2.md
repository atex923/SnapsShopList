# SnapshotBuyCheck V0.0.2 完成清單

掃描條碼後：

1. [x] 以條碼搜尋 SwiftData／CloudKit 商品資料庫。
2. [x] 找到商品時，開啟該商品的「新增採買紀錄」頁面。
3. [x] 找不到商品時，開啟「建立商品資訊」頁面。

商品資訊欄位：

- [x] 紀錄時間
- [x] 名稱
- [x] 店家
- [x] 容（重）量
- [x] 單位
- [x] 價格
- [x] 是否特價
- [x] 是否買一送一

商品照片：

- [x] 點擊相機按鈕拍攝商品照片。
- [x] 每項商品最多三張照片。
- [x] 主要頁面一次顯示一張，照片中下方提供左右箭頭切換。
- [x] 商品照片同時保存於 App 文件目錄與手機相簿。
