# 版本紀錄

## V0.0.7 (20260906)

- 商品照片控制列移到照片下方，取消黑色底板；左右功能鍵貼近角落，不再遮擋照片。
- 掃碼既有商品頁於新增按鈕上方加入「進入採買記事商品資料」。
- 首頁待買清單改為單行商品名稱、可省略條碼與垃圾桶；點擊條碼浮出完整內容，刪除前要求確認。
- 待買清單不再顯示數量及加減符號。
- 掃描條碼方格改為米藍色並移除「啟動相機」；採買記事方格移除「歷次紀錄」。
- 首頁掃描結果移除平均價格，只保留歷史最低與最高價格。
- 掃描既有商品後改顯示照片、三欄歷次價格及「新增商品資料」入口；照片支援左右切換、上三角更換及紅色減號確認刪除。
- 採買記事摘要精簡為商品名稱、最低價格、店家及紀錄時間。
- 商品詳情新增依最新時間、最低價格或店家排列；每筆先顯示時間、店家、價格，其他資料以向下箭頭展開。
- 價格記憶助手移至最下方並預設收合，展開後顯示完整統計。
- 照片檔名為空時禁止執行舊檔刪除，避免誤刪相容照片資料夾。
- 程式中文名稱與首頁標題統一改為「購物記本」，英文專案名稱改為 `SnapsShopList`；保留原 Bundle ID 與資料庫識別以延續既有資料。
- 加入購物車結合相機的 1024 × 1024 正式 App 圖示。
- 條碼掃描工作階段連同初始化都移至背景佇列，避免主執行緒卡頓警告。
- 定位新增授權與精確度狀態追蹤、約略定位提示及暫時失敗重試。
- 拆分並測試表單驗證、共用數字解析、價格計算與店家正規化識別。
- 新照片取消 Documents 重複 JPEG，只保存 SwiftData 外部影像資料；舊照片完成整併後清理重複檔案。
- 高解析照片縮放及 JPEG 編碼改至背景 Task，降低連拍儲存時的 UI 停頓。
- 商品歷史列表快取最新紀錄，避免同一商品於單次畫面更新重複排序。
- 店家查詢與刪除商品關聯待買項目改用 SwiftData Predicate，不再全表掃描。
- Log 文字檔改成按下分享時才產生，日常錯誤記錄 I/O 減半。
- 首頁移除 GeometryReader，價格統計共用已計算的最新紀錄。
- 修正商品相機使用巢狀 `dismiss()` 可能返回首頁，改由父畫面精確控制相機 sheet。
- 照片拍攝後立即寫入系統相簿；取消儲存商品資料也不影響相簿照片，失敗時顯示權限或系統錯誤。
- 商品照片改為完全選填，照片處理失敗不再阻擋商品與採買紀錄保存。
- 商品建檔相機提升至表單根畫面的獨立 `fullScreenCover`，避免巢狀 Section 狀態重建後跳回首頁。
- 重排商品／採買表單：相機移至商品欄下方，價格、購買數量、單位、容量依指定順序排列，縣市及行政區歸入 GPS 區塊。
- 分店與容量改為選填，容量未填時保存為 0 並在歷史頁顯示「未填寫」。
- 完整保存上一版於 `history/V0.0.6/`。

## V0.0.6 (20260906)

- 修正商品照相可能閃退：改用 AVFoundation 自訂拍照工作階段與錯誤處理。
- 加入支援超廣角鏡頭裝置的近拍小花模式。
- 首頁標題改為「快拍購物帳本」，移除原副標題。
- 首頁改為固定單頁，三個主要區塊採緊密配置且不需捲動。
- 上方兩個功能方格的圖示、標題與副標題高度對齊。
- 功能卡片改用 iOS 26 Liquid Glass，背景改為蘋果淺綠色。
- Log 按鈕移到頁尾作者資訊右側，圖示縮小約一半。
- 採買表單新增鍵盤隱藏按鈕。
- 舊照片移轉延後執行且成功後不再重複，改善首次畫面操作反應。
- 完整保存上一版於 `history/V0.0.5/`。

## V0.0.5 (20260906)

- 新增價格記憶助手，顯示歷史最低、平均、最高有效單價，以及最低／最高價時間與店家。
- 新增每 100 g／ml 標準單價；kg、L、cc 自動換算。
- 買一送一依實際取得雙倍件數計算真正單價。
- 新增每筆採買的購買數量與本次付款總價換算，數量預設 1 且限制為正整數。
- 首頁新增待買清單；掃描既有條碼直接加入，未知條碼銜接商品建檔。
- GPS 使用 iOS 26 MapKit 反向地理編碼，自動帶入縣市與行政區並保留手動修改。
- 新增待買項目、單筆採買紀錄及整項商品的刪除功能，破壞性操作均要求確認。
- 執行錯誤同步寫入可分享的 `SnapshotBuyCheck-runtime.log`，最多保留最近 200 筆。
- SwiftData 欄位具有預設值 1，維持 V0.0.4 舊資料相容性。
- 新增 V0.0.4 建議路線承接對照文件。
- 完整保存上一版於 `history/V0.0.4/`。

## V0.0.4 (20260906)

- 新增常用店家記憶，依最近使用時間提供快速選擇。
- 店家資料新增分店、縣市及行政區，並整合至歷史顯示與搜尋。
- 採買紀錄新增 GPS 經緯度及定位精確度欄位。
- 定位未授權或失敗時不阻擋儲存，GPS 欄位保留空白。
- 新增程式錯誤紀錄頁，最多保留最近 200 筆並可手動清除。
- 相機、資料庫、照片、相簿、GPS 與啟動移轉錯誤寫入本機錯誤紀錄。
- 新增 iOS「使用 App 期間」定位用途說明。
- SwiftData 模型以預設值與選填欄位擴充，保留舊版資料相容性。
- 完整保存上一版於 `history/V0.0.3/`。

## V0.0.3 (20260906)

- 移除掃描完成後固定 0.35 秒延遲，改由相機畫面關閉事件銜接資料表單。
- AVCaptureSession 設定、啟動及停止移至專用背景佇列。
- 新增條碼手動輸入，提供相機辨識失敗時的替代方式。
- 相機或資料庫查詢失敗時顯示明確訊息，不再停留於無回應畫面。
- 商品照片加入 SwiftData 外部儲存影像資料，改善跨裝置同步完整性。
- 舊版本機照片啟動時自動補入影像資料，保留既有資料。
- 照片儲存前縮放至最長邊 1600 點並壓縮，降低裝置與 iCloud 空間用量。
- 修正新增、刪除照片失敗時的資料庫回復與檔案清理順序。
- 新增商品、條碼及店家搜尋。
- 既有商品再次採買時自動帶入上次常用欄位。
- 強化本地化數字解析、數值範圍及重複條碼檢查。
- Debug 直接使用既有本機資料庫，避免無 iCloud entitlement 時先嘗試 CloudKit。
- 完整保存上一版於 `history/V0.0.2/`。
